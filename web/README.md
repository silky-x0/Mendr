# Mendr landing page

Prerendered TanStack Start + Tailwind v4 site (light theme, no backend).

- `pnpm dev` dev server on :3000
- `pnpm test` run vitest
- `pnpm build` prerender to `dist/client`
- `scripts/capture.sh [url]` headless Firefox screenshots into `.captures/` (serve `dist/client` on :4173 first)
